# Srushti's Pink Aesthetic Portfolio 🌸

A responsive personal portfolio website built using HTML, CSS, and JavaScript.

## Features

- Pastel pink and white design
- Responsive navigation
- Animated hero section
- About me section
- Skills cards
- Project showcase
- Education section
- Contact form validation
- Smooth scrolling
- Scroll reveal animations
- Mobile-friendly layout

## Project Files

- index.html: Website structure
- style.css: Design and responsive styles
- script.js: Navigation, animations, and form validation
- profile.jpg: Optional personal profile photo

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html in your browser.

Alternatively, install the Live Server extension in VS Code.

Right-click index.html and choose "Open with Live Server".

## Personalization

### Add a Profile Photo

Place your photo in the project folder and name it:

profile.jpg

### Update Project Links

Open index.html and replace placeholder URLs with your real project URLs.

### Update Social Links

Replace the placeholder GitHub and LinkedIn URLs with your actual profile links.

### Contact Form

The form currently validates inputs in the browser. It does not send or store messages.

To receive messages, connect a backend or a suitable form service.
